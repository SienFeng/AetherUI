# 品牌图标

分流页域名组卡片的厂商标识，文件名即 `web/service/routing_brand.go` 里的 slug
（`TestBrandIconsExist` 守着两边一致）。只收识别表用得到的那些，按原样拷贝、未改动。

| 来源 | 版本 | 许可 | 文件 |
|---|---|---|---|
| [Simple Icons](https://github.com/simple-icons/simple-icons)（npm `simple-icons`） | 16.36.0 | CC0-1.0 | 除下一行以外的全部 |
| [Lobe Icons](https://github.com/lobehub/lobe-icons)（npm `@lobehub/icons-static-svg`） | 1.101.0 | MIT（npm registry 的 license 字段；tarball 内不含 LICENSE 文件） | openai、grok、copilot、qwen、kimi、doubao、microsoft |

OpenAI、Microsoft 等已应权利方要求从 Simple Icons 移除，所以改取 Lobe Icons。

图标许可只覆盖图形文件本身；图中的标识是各厂商的商标，这里仅用于在管理界面里
标明域名组对应的服务。
